# Raisd Portal API docs

Public OpenAPI description and Swagger UI for the Raisd Portal API.

**Live docs:** https://raisd-campus.github.io/portal-api-docs/

| File | Role |
|------|------|
| [`openapi.yaml`](openapi.yaml) | Published OpenAPI 3.1 spec |

The implementation lives in the private [`control-plane`](https://github.com/raisd-campus/control-plane) repo (`portal-api/`). Keep this published copy in sync when the private `openapi.yaml` changes.
