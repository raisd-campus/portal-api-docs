Popup sections

#

Opt into Popup contentLayout=sections for 32px between related groups. PopupSection provides 16px internal spacing and optional titles/descriptions; untitled groups reserve no header space. Existing default popup bodies retain their spacing and layout. Header/footer, scrolling, focus and pending-dismissal behavior stay shared.

@raisd-campus/design-system/system/popup @raisd-campus/design-system/system/popup-section · Versioned catalogue

Field layout and overflow

#

DetailField supports opt-in 192px labels and helper descriptions aligned below their controls, with narrow-panel stacking. Text-like Input values use ellipsis and a tooltip only when clipped; read-only fields offer focus guidance while editable focus preserves typing and picker Escape behavior. Password and non-text values are excluded.

@raisd-campus/design-system/system/detail-field @raisd-campus/design-system/ui/input @raisd-campus/design-system/ui/date-picker · Versioned catalogue
