Choose the right owner

Install @raisd-campus/design-system@0.9.1 for portal-neutral visuals. Keep student enrolment, routing, account issues and Community draft policy in the student portal. Do not copy shared component source into a portal.

Read the canonical component guide before building a UI element; use the versioned package catalogue and installed TypeScript declarations for exact props. The screenshots are visual references, not interactive demos.

Install in a portal

@raisd-campus:registry=https://npm.pkg.github.com
npm install --save-exact @raisd-campus/design-system@0.9.1

@import "tailwindcss";
@import "@raisd-campus/design-system/styles.css";
@source "../node_modules/@raisd-campus/design-system/dist";

Configure GitHub Packages read access in local npm settings or CI; never commit a token. Import individual ui/* or system/* subpaths.
