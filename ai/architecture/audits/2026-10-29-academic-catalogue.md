# Academic catalogue delivery — 29 October 2026

## Delivered locally

Staff (`lecturer-portal`) now has Academic → Faculty, Programme and Modules, using released shared tiered navigation 0.20.0, shared Admin directories/workspaces, fields, panels, popups and audit. Faculty Groups, accreditation, curriculum semesters/streams/modules/prerequisites, explicit academic rules, immutable published versions/default selection, module-use projections and exact-enrolment stream assignment are implemented.

Control exposes Academic Curriculum under University Flows, including campus application, versions, mandatory independent Curriculum Review and existing-role reviewer assignment. SSO enforces the new Academic permissions and preserves existing Admissions reviewer target keys. Assignment does not grant access. The author/editor/submitter cannot approve their own curriculum through another role.

Portal API persists the catalogue and canonical publication atomically in PostgreSQL with revisions, request receipts and staff audit. Memory writers/readers are serialized, and failed persistence restores catalogue and graph state. Retry responses return a consistent, currently authorized entity/catalogue pair. Structure Programme ownership is immutable. Prerequisites must be reachable through every applicable stream.

Applicant choices use the approved effective default curriculum and configured campus calendar. Three preferences and Programme-only selection are retained. Submission snapshots pin labels and the exact version. New SSO people receive person/campus-owned persistent journeys; raw owned keys cannot use Demo password login, and only the original five Demo journeys are resettable. Secure conversion creates clean owned Student records without copying someone else's fees, teaching, registrations or results. Study Plan, registration and completion use common modules plus selected streams; historical records remain readable.
