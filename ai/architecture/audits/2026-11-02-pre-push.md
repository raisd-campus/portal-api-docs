## Evidence boundaries and limitations

Mocked UI checks establish navigation, interaction, accessibility and layout behavior. Real HTTP/PostgreSQL tests separately establish persistence, authorization, migration/concurrency behavior and synthetic end-to-end journeys. Service readiness is reported separately and is not proof of functional correctness. Live CMS/payment providers, notification delivery, hosted deployments and real-device passkey hardware are not claimed.

Production dependency scans reject high/critical findings. SSO retains moderate transitive glob/minimatch findings without a compatible non-breaking fix in the declared dependency range; static serving does not enable directory listings or accept user-supplied glob patterns. The inspected installed static plugin calls glob in its `wildcard: false` registration branch; SSO uses the default wildcard route and does not select that branch. The findings are retained as dependency-maintenance limitations rather than silently force-downgrading the Fastify plugin. The patched traversal path is covered by a containment regression. Browser-engine-specific unsupported hardware/pointer scenarios are explicitly reported as skips, not passes.
