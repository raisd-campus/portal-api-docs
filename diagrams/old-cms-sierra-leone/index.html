Existing Sierra Leone CMS — technical analysis

Inventory from the ICA Sierra Leone source & structure package (ICA_SierraLeone_Codes_&_DB_Structure_23_09_2026). Sister EMS / PHPMaker campus to Cyberjaya — useful for M5 expansion pattern matching. Not the launch system of record (ADR-1 remains Cyberjaya).

DB ems_sierraleone 345 tables 156 non-temp 6 procedures 91 triggers 9 views Dump date 23 Sep 2026
Scope. Document structure and desk surfaces only. The PHP tree, .gz portal extracts, credentials, and live student files from the package are not committed to git. Canonical agent notes: old-cms-sierra-leone.md. Cyberjaya (launch SoR): LUCT CMS / Cyberjaya analysis.
Technology shape. PHPMaker desks under sierraleone/<desk>/ — applicationcenter, registry, academic, finance, reports, setting, studentaffair. Same EMS family as Cyberjaya (r_* / f_* / b_*), with admissions mostly on ac_* instead of app_*. No Laravel payment/PDPA apps and almost no stored-procedure API surface in this dump.
