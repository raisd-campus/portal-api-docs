Raisd CMS

Canonical Raisd data model and flows for the four portals + Portal API. These are the logical ERD and DFD — not a copy of the LUCT CMS physical schema. Legacy tables stay behind the CAP-53 anti-corruption layer.

Logical / contract model Portals → Portal API → domains No physical SQL migrations yet
Entity Relationship Diagrams Institution, curriculum, delivery, student journey, finance, integration Data Flow Diagrams Context, ACL, auth, admissions, registration workflow, teaching Architecture SoR ownership, CAP-53 ACL, SDD & ADR catalogue LUCT physical ERD Legacy Cyberjaya tables — discovery only, not the Raisd model
