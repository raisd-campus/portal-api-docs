High-level comparison & target delivery

Working Group confirmation 23 Sep 2026 (Aslam): this phase keeps Cyberjaya CMS as SoR and builds modern portals via the Portal API without duplicating operational functions. Longer term still aims for a unified one-stop CMS — progressively, on verified gaps, with a migration strategy.

Horizon What we deliver System of record Milestone
This phase Modern Applicant / Student / Lecturer / Staff experiences via Portal API; staff ops stay on verified old desks unless a gap is proven Existing Cyberjaya CMS M1–M4
Admissions launch Apply → evidence → track → offer → enrol Existing CMS M2
Core student portal Student journeys + paired lecturer/staff paths (or verified old desk) Existing CMS M3
Cyberjaya pilot Integrated acceptance, training, ops readiness Existing CMS + Portal API M4
Longer term Campus expansion + progressive consolidation toward one-stop CMS Migrate domain-by-domain after verified gap + written migration strategy M5+
