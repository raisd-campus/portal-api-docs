Critical path (frontend)

Order for closing online-registration acceptance gaps.

  1. Applicant CAP-02/03 — Process A field parity, durable upload, Portal API save.
  2. Applicant CAP-07 — Live offer view and durable acceptance/provisioning; mock acceptance/handoff exists.
  3. Staff CAP-03/05/06/07 — Registry review → offer → first enrolment (or verified old CMS).
  4. Student CAP-10 — Live term write + Process B Add/Drop after first confirm.
  5. Lesotho overlays — LGCSE/Sesotho + NMDS; exclude Malaysia EMGS/NOC from M4 default.
