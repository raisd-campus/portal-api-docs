Lesotho CMS — pilot feature analysis

Pilot project campus for Raisd (Working Group, 3 Oct 2026). Reverse-engineered from Faid’s newer Admin / Student CMS screenshots (WhatsApp Working Group CMS 2026). No DB dump yet — this page is a capability / flow analysis, not a physical ERD. Old CMS family tree ≈ Botswana / Cyberjaya (Vara).

M4 pilot acceptance Screenshot SoT NMDS + LGCSE 369 tables invent. limkokwing.ac.ls
Why Lesotho (Read.ai, 3 Oct 2026). Sponsor wants Lesotho-first (not Cyberjaya-first) plus weekly % progress; Lesotho is the revenue / adoption priority; Raisd must meet government requirements and match the campus’s newer CMS; framed as a pilot project with other campuses in parallel (Eswatini may follow). Full rationale: lesotho-pilot.md · overview highlight: overview.md.

Gaps vs Raisd Schema v3 Demo (today)

  1. NMDS ≠ DTEF — map nmds / AssistStdAcc / term bills; no TEF client.
  2. LGCSE extract — subject/grade rows + Sesotho + Examinations Council metadata.
  3. 3-step admissions + rank/score — richer than thin applicant Demo.
  4. Graduation clearance — multi-dept gates + gown/grad fee precondition.
  5. LSL finance + SoR print/QR — campus currency + staff deliverable.
  6. CAP-53 write path — reads mapped; Live SoR (old CMS vs Schema) still WG.
