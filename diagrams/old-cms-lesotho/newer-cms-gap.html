Lesotho newer CMS — gap vs Raisd

What Raisd still has to cover vs the staging Admin benchmark (luct.vercel.app, term 2026-07). Demo deepen (28 Oct) closed many Staff desks on sample data — Live SoR write-back is still not claimed. Playback: demo-role-playback.html.

No personal records. Counts, menus, routes, statuses, and fee names only. Names, emails, student numbers, marks, and documents stay out of this site.

15. Gap against the Raisd system under development

Raisd status below is the knowledge base as of 28 Oct 2026. Live is not claimed for any row. Demo means sample or session behaviour through the Portal API on *.lesotho.raisd.co. Staff Admin includes applicants, students, payments, fees, sponsors, graduations, certificates, remarks, academic, analytics, discipline, registrations, and access. Control owns custom roles. Sign-in is Raisd SSO / Keychain.

What Raisd already covers in Demo (and still is not Live CMS)

  • Applicant submission, evidence, offer, and accept on SSO with LSL fee presentation.
  • Student registration, finance, funding, remarks as Demo screens.
  • Staff desks: applicants, payments, fees, sponsors, students (12-tab file), registrations, graduations, certificates, remarks, academic, analytics, discipline, access.
  • Lesotho Keychain position roles and Control Flows catalogues.
  • Campus landing at lesotho.raisd.co.

Storyboard: demo-role-playback.html. Those Demo surfaces are not equivalent to Live SoR desks in sections 3–13.

Pilot cut — remaining after Demo deepen

  1. Live CAP-53 SoR read/write-back (registry file stays Demo graph).
  2. FM-16 timetable generator / venues.
  3. FM-09 banks / debtors / payment plans.
  4. Letter templates and Live QR certificate pipeline.
  5. FM-02 Applicant rewrite (Faid-owned).
