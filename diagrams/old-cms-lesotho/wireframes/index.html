Lesotho Demo desk wireframes

Lo-fi wireframes for every Staff Admin Demo desk mapped from the ingested newer-CMS Lesotho screenshots and FM-03…FM-18 catalogue. Desktop shells use a two-level side menu: labelled PortalSidebar primary nav, plus a contextual aside sub-side to its right (LinkedList rhythm — Admissions / Registry / Finance / Completions / Teaching / Oversight). Text uses ellipsis + minmax(0,1fr) grids so labels never overlap. Frames call out the shared design-system elements to compose — not Live CMS chrome.

Wireframe only. Demo ≠ Live. Sources: feature modules · screenshot inventory · DS 0.19.8 pack · README
