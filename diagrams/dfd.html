Process catalogue

What each Level-1 process owns.

IDProcessInputsOutputs / side effects
1.1 Role portal webs User actions in apply / student / teach / staff HTTPS to Portal API; rendered views
1.2 Auth & session Credentials / IdP assertion Bearer token; session record (TTL 12h today)
1.3 Portal API RPC POST /v1/portal/:method + bearer { result, cms } envelope
1.4 Admissions Application drafts, evidence files, acceptances CMS application / offer / first enrolment
1.5 Academic & registration Module selections, credit overrides Registrations, study-plan views
1.6 Finance Invoice queries, payment proofs Allocations (bursary), funding awards
1.7 Teaching & assessment Materials, attendance, marks, submissions Published results (student-visible)
1.8 Forms / immigration / graduation Form answers, case docs Case status, linked invoices
1.9 CMS adapter Domain write/read intents CMS transactions; stub ack until CAP-53
