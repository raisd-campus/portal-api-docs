Online class — user guide

Step-by-step Demo Partial guide for lecturers and students: start or join a live class on Lesotho Raisd portals, open the dark Raisd Classroom, use host tools (locks, waiting room, breakouts, whiteboard, notepad, polls, chat file share, recording, RTMP, AI), leave or end the session, and review Past Class. Screenshots and videos from the GRD301 walkthrough.

Demo Partial Not Live CAP-26
Demo ≠ Live. Sample / session data only. Join media uses Raisd classrooms (classrooms.raisd.co). Do not treat this as Live production training. Markdown SoT: docs/ai/frontend/online-class-user-guide.md.

Quick start

Lecturer (host)

  1. Sign in at staff.lesotho.raisd.co
  2. Open Classrooms → module (e.g. GRD301) → Live class
  3. Click Start class
  4. Virtual classroom modal opens → set mic/cam → join
  5. Use lobby End class when finished

Student (participant)

  1. Sign in at student.lesotho.raisd.co
  2. Open Academic → Modules → module → Live class
  3. When Join is enabled, click Join
  4. Virtual classroom modal opens → set mic/cam → join
  5. Click lobby Leave class when finished

Prefer Keychain Open filled (Lesotho) into SSO. Demo accounts in captures: Adam Watson (lecturer) · Rizal Hakim (student).

File upload & sharing

Everyone can share files in Public Chat (unless the host locks file share). Use the paperclip, paste an image, or drag-and-drop into the composer. Allowed types include images, PDF, Office docs, zip, and common audio/video — up to 50 MB. Hosts can also attach office files on the whiteboard. Lock path: More options → Meeting Lock Settings → chat files.
