Online class — user guide

Step-by-step Demo Partial guide for lecturers and students: start or join a live class on Lesotho Raisd portals, open the dark Raisd Classroom, use host tools (locks, waiting room, breakouts, whiteboard, notepad, polls, chat file share, recording, RTMP, AI), leave or end the session, and review Past Class. Screenshots from the GRD301 walkthrough (screenshot journeys only).

Demo Partial Not Live CAP-26
Demo ≠ Live. Sample / session data only. Join media uses Raisd classrooms (classrooms.raisd.co). Do not treat this as Live production training. Markdown SoT: docs/ai/frontend/online-class-user-guide.md.

Quick start

Lecturer (host)

  1. Sign in at staff.lesotho.raisd.co
  2. Open Classrooms → module (e.g. GRD301) → Live class
  3. Click Start class
  4. Virtual classroom modal opens → set mic/cam → join
  5. Use lobby End class when finished
  6. Scroll to Past Class → Re-watch / Open notes / Open material (details)

Student (participant)

  1. Sign in at student.lesotho.raisd.co
  2. Open Academic → Modules → module → Live class
  3. When Join is enabled, click Join
  4. Virtual classroom modal opens → set mic/cam → join
  5. Click lobby Leave class when finished
  6. Scroll to Past Class → Re-watch / Open notes / Open material (details)

Prefer Keychain Open filled (Lesotho) into SSO. Demo accounts in captures: Adam Watson (lecturer) · Rizal Hakim (student).

Public Chat ↔ portal Community

Demo Partial: real messages sync both ways for the module Community conversation (GRD301). Classroom Public Chat posts via POST /v1/live-class/chat-mirror; Community replies return through GET /v1/live-class/community-chat. When the lecturer starts, Community shows a start notice with a Join live class button that opens the Live class lobby. After End class, that Join CTA is removed (no rejoin), chat remains in Community, and Past Class holds transferred media. Private DMs are not mirrored.

File upload & sharing

Everyone can share files in Public Chat (unless the host locks file share). Use the paperclip, paste an image, or drag-and-drop into the composer. Allowed types include images, PDF, Office docs, zip, and common audio/video — up to 50 MB. Hosts can also attach office files on the whiteboard. Lock path: More options → Meeting Lock Settings → chat files.

Past Class materials — how to open them

OL-60-lite Demo Partial. Past Class is on the same Live class lobby used to start or join — there is no separate menu.

Where to go

RolePortalPath
Lecturer staff.lesotho.raisd.co Classrooms → module (e.g. GRD301) → Live class → scroll to Past Class
Student student.lesotho.raisd.co Academic → Modules → module → Live class → scroll to Past Class

You can open Past Class before a live session (Demo completed timetable fixtures already appear) or after Leave / End class.

What each button does

Each asset line is the title with its action button in a shared right column. Group headings already name the kind (Re-watch / Notes / Shared materials), so rows stay aligned across history and notes.

Group on the rowButtonOpens
Re-watch Re-watch Class recording in a modal player (Portal-hosted Demo MP4, or cloud recording after End class via Portal media proxy)
Notes Open notes Shared lecture notes in a modal (Demo PDF, or transferred notepad/artifact when available)
Shared materials Open material Listed files such as an assignment brief in a modal (Demo PDF list; live artifacts when transferred)

Steps

  1. Sign in and open the module Live class lobby (paths above).
  2. Scroll to the Past Class panel under the live session controls.
  3. Pick a completed session. Demo history for GRD301 shows earlier fixtures without needing End class first.
  4. Under that session:
    • To replay video → under Re-watch, click Re-watch → modal player opens.
    • To read notes → under Notes, click Open notes → notes open in the modal.
    • To get shared files → under Shared materials, review the list, then click Open material → the file opens in the modal.
  5. In the modal use Open in new tab if you prefer a separate window, or Close to return to the lobby.
  6. If a button is missing, that asset is not downloadable yet (still processing or unavailable-demo).

Known issues — UltaHost interim SFU (20 Nov 2026)

Demo Partial media now runs on the Demo UltaHost VPS. During cutover, LiveKit could mark publisher quality LOST and full-reconnect about every 17 seconds.

IssueWhat to do
Connection interrupted. Reconnecting… looping Close the classroom modal/tab completely, then Open classroom again so the LOST-neuter client loads.
Mic or camera turns off by itself Same leave cycle unpublishes tracks — not mute-on-start. Re-open after the client fix; toggle mic/cam if still off.
Cloud REC / “No recorder” Expected on this interim box — chromedp recorder stays off so the host session stays stable. SFU and chromedp must not share the same small VPS — diagram.
Compose CPU / memory LiveKit already had no Docker caps (idle use is tiny). VPS compose raises cpu_shares / mem_reservation; Jenkins is scaled down during live proof.
